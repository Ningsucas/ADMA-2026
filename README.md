## Abstract

Learning-based cardinality estimation (CE) has emerged as a promising alternative to statistics-based techniques. Yet its reliability remains an open question: directional bias, upper-tail risk, and degradation under data or workload shifts. We adopt a data model-centric perspective, introducing a unified analytical framework spanning query encoding, data feature extraction, and model adaptation, and argue that the most informative classification axis shifts across data models. A relational case study probes PostgreSQL bias and MSCN workload-shift behavior.
